# Contributing to Xencard Keeper

Thank you for your interest in contributing to Xencard Keeper!

## Development Setup

1. Fork the repository
2. Clone your fork: `git clone git@github.com:YOUR_USERNAME/xencard-keeper.git`
3. Navigate to the project: `cd xencard-keeper`
4. Install dependencies: `npm install`
5. Start the development server: `npm start`

## Code Style

- Use TypeScript strict mode
- Follow the existing code style
- Run `npm run lint` before committing
- Run `npm run format` to format code
- Run `npm run typecheck` to verify TypeScript

## Commit Guidelines

- Use conventional commits: `feat:`, `fix:`, `test:`, `docs:`, etc.
- Keep commits small and focused
- Write clear commit messages

## Development Phases

See `AGENTS.md` for the complete development roadmap and architectural guidelines.

## Testing

- Write tests for business logic
- Test on real devices when possible
- Test offline functionality
- Test performance with large datasets

## Pull Requests

1. Create a branch from `main`
2. Make your changes
3. Test thoroughly
4. Submit a pull request with a clear description

## Questions?

Open an issue or contact the maintainers.
